# 部署与第三方能力边界

## 发布前检查

数据库迁移已包含领域表和运行中计时器表。发布前运行 `pnpm check`、`pnpm test` 与 `pnpm build`；之后创建项目检查点，并由项目拥有者在界面中点击 **Publish**。发布后，OAuth 回调、tRPC、对象存储与 `/api/scheduled/anchor` 才可被正式访问。

| 能力 | 已实现边界 | 发布后的配置动作 |
| --- | --- | --- |
| 账户与跨设备同步 | Manus OAuth + MySQL + tRPC；任务与时间事实均归属当前用户。 | 用户登录后自动建立资料记录。 |
| 5 分钟违约核对 | `/api/scheduled/anchor` 根据安全的定时身份调用服务端事实记录。 | 在发布后通过 `automation.configure` 为 `time_facts` 启用任务。 |
| 周度预览与最终报告 | 周报告为可重复生成的快照；不会改写任务历史。 | 为 `weekly_preview` 与 `weekly_final` 启用任务。首版默认以 Asia/Shanghai 的 UTC 对应时间配置。 |
| 语音输入 | 浏览器 `MediaRecorder` 上传不超过 16MB 的 webm/mp3/wav/ogg/m4a；服务端转写后调用结构化任务提取。 | 浏览器需要麦克风权限；内置 AI 调用消耗项目额度。 |
| AI 结构化任务 | 服务端使用运行时模型目录选择可用模型，并以严格 JSON schema 校验输出；失败时退回直接任务入库。 | 不需要暴露 API 密钥。 |
| 动态宇宙 | Three.js 在 WebGL 中呈现恒星、行星与卫星；数据来自云端 Goal、Project、Task。 | 不支持 WebGL 的环境可保留简化静态展示。 |
| 好友星云 | 双向好友与显式可见度授权；访客只获得摘要，不发送任务标题、笔记、截止时间或时间事实。 | 资料、目标、项目与任务默认为私密。 |

## 通知与提醒

项目内的通知能力用于项目拥有者的运行告警，而非用户之间的私信。当前版本保存了可部署的定时回调和报告快照；如需发送手机推送、短信或邮箱提醒，应在后续接入相应的第三方通道、用户同意与退订机制后再开启。不得将任务标题或时间事实发送给未经授权的好友。

## 运行限制

定时任务必须由已发布站点接收，不能依赖浏览器打开、`setInterval` 或本地开发服务器。所有时间戳以 UTC 存储，按个人资料时区展示和判断“当天内”。若用户修改时区，历史事件的发生时间不变，只改变后续默认紧急判定与界面展示。
